Comment lire le score TERROIR ?

Le score TERROIR combine quatre indicateurs observés sur les 14 derniers jours, comparés à une référence de 90 jours :

  • Type d'événements — part de signaux conflictuels ou sécuritaires
  • Ton médiatique — positif ou négatif dans les sources
  • Volume d'activité — nombre d'événements signalés
  • Diversité des sources — variété des médias couvrant la zone
Le score ne prédit pas une crise. Il indique qu'une zone mérite une vérification humaine. L'analyse terrain reste la référence.
Normal Score inférieur à 2.0
Précaution Score entre 2.0 et 3.0

  • Surveiller l'évolution pendant 24h
  • Préparer une note courte de situation
Alerte Action immédiate
  • Contacter les relais terrain
  • Limiter les déplacements non essentiels
  • Informer le coordinateur sécurité
  • Préparer une décision de repositionnement si confirmé

Comment fonctionne le signalement
  1. Remplissez le formulaire avec les informations disponibles.
  2. Votre signalement est enregistré avec le statut non vérifié.
  3. L'équipe TERROIR examine et valide les signalements crédibles.
  4. Une fois validé, il apparaît sur la carte et contribue au Score de Tension Territorial (STT).
Confidentialité des données

Les informations de contact (nom, téléphone, email) sont utilisées uniquement pour vérifier votre signalement si nécessaire.

Elles ne sont jamais affichées sur la carte ni partagées publiquement. Vous pouvez rester complètement anonyme.
